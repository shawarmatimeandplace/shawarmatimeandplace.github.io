# Code of Conduct

We expect everyone participating in this repository to be respectful, constructive, and considerate. Harassment, discriminatory language, personal attacks, and publication of someone else's private information are not acceptable.

If you experience or witness unacceptable behavior in a repository issue or pull request, contact [info@shawarmatimeandplace.ca](mailto:info@shawarmatimeandplace.ca). Repository maintainers may edit or remove contributions and restrict participation when necessary.
