# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue, pull request, or discussion. Send a report to [info@shawarmatimeandplace.ca](mailto:info@shawarmatimeandplace.ca) with **Security vulnerability report** in the subject line.

Include, where possible:

- The affected page, URL, or component.
- Steps to reproduce the issue and its potential impact.
- Any relevant screenshots, request/response details, or proof of concept. Do not include real customer or personal data.

Please give us a reasonable opportunity to investigate and address the issue before publicly disclosing it. We aim to acknowledge reports within five business days and provide a status update within 30 days. These are targets, not guaranteed response times.

## Scope

This policy covers the website and source code maintained in this repository. Third-party services and software are outside our direct control; please report issues in those systems to their respective security teams.

## Supported versions

Security fixes are made for the current version of the website. We do not commit to backporting fixes to older versions.
