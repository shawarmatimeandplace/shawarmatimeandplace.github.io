# Support

## Website issues

For a reproducible problem with the website, open a [bug report](https://github.com/shawarmatimeandplace/shawarmatimeandplace.github.io/issues/new?template=bug_report.yml). Include the affected page and browser/device details, but do not post sensitive personal information.

## Business, menu, or order questions

For business inquiries, contact [info@shawarmatimeandplace.ca](mailto:info@shawarmatimeandplace.ca).

## Security issues

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) to contact us privately.
